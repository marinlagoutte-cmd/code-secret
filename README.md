# Code secret

Jeu de déduction au principe du Mastermind : trouver un code de pions de couleur grâce aux réponses noires (bonne couleur, bonne place) et blanches (bonne couleur, mauvaise place).

Jouer : https://marinlagoutte-cmd.github.io/code-secret/ (ordinateur ou téléphone).

Modes : Solo, Défi du jour, Contre l'ordi (algorithme de Knuth), 2 joueurs sur le même appareil. Page autonome en HTML, CSS et JavaScript, sans serveur.
