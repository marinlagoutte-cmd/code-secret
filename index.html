    L'ordi réfléchit

    Règles du jeu

    Le but

    Trouver le code secret : une rangée de 4 pions de couleur choisis parmi 6 (jusqu'à 6 pions et 8 couleurs dans les réglages). Une même couleur peut revenir plusieurs fois, sauf si le réglage l'interdit.

    À chaque essai

    Tu proposes une rangée complète. La réponse s'affiche à droite :

    • pion noir : une bonne couleur à la bonne place ;
    • pion blanc : une bonne couleur, mais mal placée.

    Les noirs sont toujours rangés en premier : la position des pions de réponse ne dit pas quel pion est concerné. Tu as 10 essais (8 à 12 selon les réglages).

    Couleurs répétées

    Chaque pion du code ne compte qu'une fois. Code , essai : 1 noir (le premier rouge) et 2 blancs (le vert et le second rouge). Le jaune ne rapporte rien.

    Les modes

    • Solo : l'ordinateur tire un code au hasard. 💡 te propose un essai si tu bloques.
    • Défi du jour : le même code pour tout le monde aujourd'hui, réglages classiques, une seule partie. Ta série de jours gagnés est comptée et tu peux partager ton résultat.
    • Contre l'ordi : manches alternées. Tu cherches le code de l'ordi, puis il cherche le tien. Il ne triche pas : il ne raisonne qu'avec les réponses.
    • 2 joueurs : sur le même appareil. Chacun cache un code à son tour ; un écran de passage évite de voir le code de l'autre.

    Les points (contre l'ordi, 2 joueurs)

    Celui qui cache le code marque 1 point par essai de l'autre, plus 1 point de bonus si son code n'est pas trouvé. Chacun cache autant de fois (nombre de manches pair) ; le plus de points gagne.

    Commandes

    • Touche une couleur : elle remplit le trou entouré, puis passe au suivant.
    • Touche un trou pour le choisir ; touche-le encore pour le vider.
    • Touche une rangée déjà jouée pour la recopier.
    • Clavier : 1…8 couleurs, ← → trou, ⌫ efface, Entrée valide.
